# detaillac_course05

This project writes hello to the world with the help of our teacher's setup. It's purpose is educational: to learn how to create and push a project from vs code to git.

## Installation

```bash
git clone git@github.com:emlyon-hids-python-2026/detaillac_course05.git
cd detaillac_course05
uv sync
```

## Usage

```bash
uv run scripts/demo.py
```

## Project structure

- `data/`: datasets (not tracked by git)
- `notebooks/`: Jupyter notebooks
- `scripts/`: Python scripts
- `src/`: Python package
